# Skåne IT Support – presentation (English)

**1. Introduction:** I am studying frontend and full-stack development. This is a responsive website I developed to practise React, CSS and user-friendly design.

**2. Project overview:** Skåne IT Support is a demonstration website that combines a local Scanian visual identity with three IT-support service categories. It is not a live service business.

**3. Planning:** I organised the site into seven components: Header, Hero, Services, About, Gallery, Contact and Footer. I reused the same colour palette and layout rules.

**4. Live demo:** Show the homepage, click Services, open the mobile menu, show the gallery, and test the contact form. Explain that no message is actually sent.

**5. Development:** React components organise the site. JSX defines the content, CSS controls the design, and React useState handles opening and closing the demo contact form. Vite runs the development server.

**6. Challenges:** Responsive layouts, keeping images sharp, navigation and making the form's behaviour clear. I tested the site on desktop and mobile.

**7. AI:** I used ChatGPT for feedback, explanations and code suggestions, then reviewed and tested the result. I can explain the main components and how they work together.

**8. Reflection:** I learned how React components, CSS Grid, media queries and component state can work together to make a complete frontend website.

**9. Questions:** Be ready to show App.jsx and one component, explain how styles.css/App.css relates to JSX, and why the contact form is a demo.
