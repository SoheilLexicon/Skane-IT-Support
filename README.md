# Skåne IT Support

Ett individuellt frontend- och webbdesignprojekt. En responsiv demonstrationswebbplats med skånsk profil, IT-tjänster, bildgalleri och ett kontaktformulär i demoläge.

**Teknik:** React, Vite, JavaScript/JSX, CSS Grid, Flexbox, Lucide React och Git/GitHub.


## Kodens sju delar

- `src/components/Header.jsx` – logotyp, navigation och mobilmeny.
- `src/components/Hero.jsx` – startsidans bakgrund, rubrik och knappar.
- `src/components/Services.jsx` – tre återanvändbara tjänstekort från en lista.
- `src/components/About.jsx` – projektbeskrivning med foto.
- `src/components/Gallery.jsx` – skånska bilder med responsiv Grid.
- `src/components/Contact.jsx` – öppningsbart formulär med React state och demobekräftelse.
- `src/components/Footer.jsx` – sidfot och länk tillbaka till toppen.

`src/App.jsx` sätter ihop delarna och styr om kontaktformuläret är öppet. `src/App.css` innehåller de gemensamma designreglerna.


**Viktigt:** Formuläret skickar och lagrar inga uppgifter. Webbplatsen är en skolprojekt-demo, ingen bekräftad kommersiell tjänst.
