
## Project Goals

- Build a modern and responsive business website.
- Practise React components and JSX.
- Use CSS Grid and Flexbox for responsive layouts.
- Create clear navigation and reusable components.
- Develop an interactive contact form.

## Development Process

1. Plan – Defined the website's purpose and content.
2. Design – Selected colours, images and layout.
3. Develop – Built the website using React, Vite and CSS.
4. Test – Tested navigation, layout and contact form.
5. Deploy – Prepare the website for public access.
6. Explain – Document the code and learning process.

## Challenges & Learning

- Understanding how React components work together.
- Organising CSS and responsive layouts.
- Managing images and project files.
- Learning how React state controls the contact form.
